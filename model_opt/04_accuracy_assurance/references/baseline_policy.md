# 基线确认：操作模板

> 基线管理的原则和规则见主文件 SKILL.md「二、确认基线」。本文件仅提供操作层面的模板。

## 询问模板

官方基线缺失时，至少问清：
- 是否已有 GPU 侧运行结果？
- 结果文件在哪个目录？含哪些内容（日志、推理输出、指标文件）？
- 希望 agent 直接读取目录分析，还是只给对比方法由用户自行执行？

## 报告措辞

根据实际对齐程度，使用精确的结论表述：

- 只做了 CPU 对比："当前仅完成 CPU vs NPU 调试性比较，不作为最终精度对齐结论"
- 只对齐了官方示例："官方示例级推理结果基本对齐，尚未覆盖完整评测集"
- Level 1 通过但未做 Level 2："单步等价验证通过，尚未完成全量验证"
- Level 1.5 通过："模型直接输出有偏差，但下游任务指标在合理范围内，功能等价确认"
