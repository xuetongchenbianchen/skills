# 基线确认：操作模板

> 基线管理的原则和规则见主文件 SKILL.md「二、确认基线」。本文件仅提供操作层面的模板。

## Baseline 完整性检查（回归验证前）

使用 Phase 1 保存的 baseline 前，确认：
- 输出文件齐全：每个精度样本都有输出记录，且对应输入可由脚本确定性重建
- 输入一致：当前验证与 baseline 采集使用相同输入数据（对比脚本自包含，输入路径显式）
- 采集环境已记录（设备、dtype、框架版本），与当前运行环境一致
- baseline 是优化前原始实现的输出：确认采集时未混入任何优化 patch（检查方式见 [05_engineering/SKILL.md](../../05_engineering/SKILL.md)「验证 baseline 有效性」）

## 报告措辞

根据实际验证完成度，使用精确的结论表述：

- Level 1 通过但未做 Level 2："单步等价验证通过，尚未完成全量验证"
- Level 1.5 通过："模型直接输出有偏差，但下游任务指标在合理范围内，功能等价确认"
